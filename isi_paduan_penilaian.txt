D.  Query PostGIS Wajib (sesuai tipe vektor yang dipilih)
Mahasiswa wajib mendemonstrasikan minimal 4 query berikut sesuai tipe vektor yang dipilih. Query harus dijalankan langsung di hadapan dosen penguji menggunakan psql, pgAdmin, atau dieksekusi dari aplikasi.

Tipe	Query Wajib Didemonstrasikan	Contoh Sintaks (PostGIS)
POINT	1. Insert titik dari koordinat (lat, lon)
2. Cari titik terdekat (nearest neighbor)
3. Cari titik dalam radius tertentu
4. Hitung jarak antar dua titik	ST_MakePoint(lon,lat)::geography
ORDER BY geom <-> ST_Point(...)
ST_DWithin(a.geom, b.geom, 500)
ST_Distance(a.geom, b.geom)
LINE	1. Insert garis dari array titik
2. Hitung panjang jalur (meter)
3. Cari garis yang berpotongan area
4. Buffer di sekitar garis	ST_GeomFromText('LINESTRING(...)',4326)
ST_Length(geom::geography)
ST_Intersects(line.geom, area.geom)
ST_Buffer(line.geom::geography, 50)
POLYGON	1. Insert poligon dari koordinat
2. Hitung luas area (m² / hektar)
3. Cek titik berada di dalam poligon
4. Tampilkan poligon yang berpotongan	ST_GeomFromText('POLYGON(...)',4326)
ST_Area(geom::geography)
ST_Within(point.geom, poly.geom)
ST_Intersects(a.geom, b.geom)
